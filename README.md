# LangChain Agent Workflows

This repository contains two LLM-based agent workflows developed using LangChain as part of a university Multi-Agent Systems course.

## Projects

### 1. Algorithm Solver Agent

An LLM-based agent designed to process algorithmic problems expressed in natural language.

The workflow identifies the required problem-solving approach, executes the corresponding algorithm, and returns structured information such as:

- Algorithm name
- Execution time
- Final result

### 2. Structured Information Extraction Agent

An agent designed to extract structured information about individuals from natural-language queries and store the results in a Pandas DataFrame.

The workflow also considers missing or unavailable attributes and structured data handling.

### 3. Research Paper Analysis Agent

A LangGraph-based conversational workflow for interactive analysis of academic research papers.

The agent supports:

- Paper summarization
- Main objective and result extraction
- Question answering
- Research question extraction
- Weakness analysis
- Research idea generation
- Iterative idea refinement
- Conversation memory
- Conditional routing between specialized agents
