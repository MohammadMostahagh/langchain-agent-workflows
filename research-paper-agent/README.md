# Research Paper Analysis Agent

A LangGraph-based conversational agent for analyzing academic research papers.

## Features

- Research paper summarization
- Main objective extraction
- Key result extraction
- Question answering about the paper
- Research question extraction
- Weakness identification
- Research idea generation
- Iterative refinement of research ideas
- Conversation memory
- Conditional routing between specialized workflow nodes

## Input

The workflow is designed to work with academic papers and enable an interactive conversation about their content.

## Technologies

- Python
- LangGraph
- LangChain
- Large Language Models (LLMs)

## Academic Context

This project was developed as part of a university Multi-Agent Systems course.
